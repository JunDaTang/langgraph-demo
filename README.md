# langgraph-demo

## 如何使用
1. 装个uv，安装见：https://docs.astral.sh/uv/getting-started/installation/
2. 打开终端，在项目主目录下执行`uv sync`
3. 运行`.venv\Scripts\activate.bat`进入python环境，执行`python "sgg\chapter02-quick start\2.2简单示例.py"`
